## INugetFeedClient
Looks up package versions on a NuGet feed.
><b>Remarks:</b> Implementations are best effort: a lookup that cannot be answered (no network, an unknown package, a feed that answers something unexpected, a cancellation) gives <see langword="null" /> instead of throwing, so a caller such as a start-up update check never fails because of the feed.

## NugetFeedClient
Looks up package versions in the flat container (package base address) resource of a NuGet v3 feed, by default the one on nuget.org (`https://api.nuget.org/v3-flatcontainer`).
><b>Remarks:</b> The latest stable version of a package is read from `{base}/{package-id-lowercase}/index.json`. A version found is cached per instance and package id, so asking again costs no request; a failed lookup is not cached and is tried again next time.<br>Every failure - no network, a non-success status, a captive portal's HTML page, an index of another shape, a timeout or a cancellation - gives <see langword="null" />; nothing is thrown except for an invalid package id.
<b>Code example:</b>
>```csharp
>var client = new NugetFeedClient();
>var latest = await client.GetLatestStableVersionAsync("Atc", cancellationToken);
>```
