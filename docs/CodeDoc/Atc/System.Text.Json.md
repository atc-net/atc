### Static Methods

#### CopyTo
>```csharp
>void CopyTo(this JsonSerializerOptions source, JsonSerializerOptions target)
>```
><b>Summary:</b> Copies every setting and converter from `source` onto `target`, so `target` serializes the same way.
>
><b>Parameters:</b><br>
>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`source`&nbsp;&nbsp;-&nbsp;&nbsp;The options to copy from.<br />
>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`target`&nbsp;&nbsp;-&nbsp;&nbsp;The options to copy onto; must not have been used for serialization yet.<br />
>
><b>Remarks:</b> Use it where the options instance cannot be replaced, only configured, e.g. ASP.NET Core's `JsonOptions.JsonSerializerOptions`: `services.Configure&lt;JsonOptions&gt;(o =&gt; JsonSerializerOptionsFactory.Create().CopyTo(o.SerializerOptions))`. Where a new instance is fine, use the `System.Text.Json.JsonSerializerOptions.#ctor(System.Text.Json.JsonSerializerOptions)` copy constructor instead.<br>The converters of `target` are replaced by those of `source`. `System.Text.Json.JsonSerializerOptions.TypeInfoResolver` is only copied when `source` has one, so a resolver that `target` needs (as ASP.NET Core's options do) is kept. The obsolete `IgnoreNullValues` is not copied; `System.Text.Json.JsonSerializerOptions.DefaultIgnoreCondition` is.
