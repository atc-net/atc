## MetricsHealthCheckPublisher
Publishes the latest health check results as metrics, so they can be charted and alerted on (e.g. through OpenTelemetry), with one measurement per health check tagged `health_check.name`: <list type="bullet"><item><description>`health_check.status`: 0 = Unhealthy, 0.5 = Degraded, 1 = Healthy.</description></item><item><description>`health_check.duration`: how long the check took, in seconds.</description></item></list>
><b>Remarks:</b> Register it with `services.AddHealthChecks().AddMetricsPublisher()`, and export the meter, e.g. `.WithMetrics(m =&gt; m.AddMeter(MetricsHealthCheckPublisher.MeterName))`. How often the checks run is set by `Microsoft.Extensions.Diagnostics.HealthChecks.HealthCheckPublisherOptions`.
